🏠 티끌모아가 새 주소로 이사했어요

새 주소

이 기기는 기기연결이 켜져 있어요. 아래 버튼을 누르면 새 주소가 열리고 연결 코드가 채워져요. [연결]만 누르면 내용이 그대로 따라와요.

새 주소로 옮기기

혹시 몰라 백업 파일도 받아 두면 더 안전해요.

이 기기에 적어 둔 내용이 있어요. 새 주소로 옮기려면:

  1. 아래 [백업 파일 받기]를 눌러요.
  2. [새 주소 열기]를 누르고, 새 주소에서 앱을 설치해요.
  3. 새 앱에서 ⋯ → 백업복원을 누르고 받은 파일을 골라요.
새 주소 열기

이 기기에는 옮길 내용이 없어요. 새 주소에서 바로 시작하면 돼요.

새 주소 열기

새 주소에서 앱을 설치한 뒤에는 홈 화면의 예전 아이콘을 지워도 돼요. 예전 아이콘을 열면 이 안내가 나와요.
